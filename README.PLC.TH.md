## 📌 **สรุปประวัติและวิสัยทัศน์ทางวิชาชีพ (Professional Summary)**
สวัสดีครับ ผม **รฐนนท์ แสงรุ่งสว่าง** วิศวกรคอมพิวเตอร์ที่มีความหลงใหลในสถาปัตยกรรมระบบ (Systems Architecture), การพัฒนาซอฟต์แวร์ควบคุม และระบบอัตโนมัติทางอุตสาหกรรม (Industrial Automation) มีพื้นฐานทางเทคนิคต่อเนื่องตั้งแต่ระดับอิเล็กทรอนิกส์ (ปวช.), เทคโนโลยีคอมพิวเตอร์ (ปวส.) จนสำเร็จการศึกษาวิศวกรรมศาสตรบัณฑิต (วศ.บ. คอมพิวเตอร์) จากสถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง (KMITL)

เป้าหมายและความเชี่ยวชาญของผมมุ่งเน้นการพัฒนาระบบอัตโนมัติ (Automation Host), การผสานระบบซอฟต์แวร์เข้ากับเครื่องจักรและ PLC (System Integration), การสื่อสารโปรโตคอลอุตสาหกรรม และการจัดการท่อส่งข้อมูลการผลิต (MES / ERP Integration) เพื่อยกระดับประสิทธิภาพและความแม่นยำสูงสุดในสายการผลิต

## ⚙️ **ความเชี่ยวชาญหลัก (Core Competencies)**
* 🔧 **การบูรณาการระบบและซอฟต์แวร์ควบคุม (Automation & System Integration):** พัฒนาซอฟต์แวร์ควบคุมเครื่องจักร (Automation Host) ด้วย C#/.NET เชื่อมต่อระหว่างเครื่องจักร, PLC และระบบฐานข้อมูลกลางโรงงาน (MES / ERP)
* 🛠️ **โปรโตคอลอุตสาหกรรมและเครือข่าย (Industrial Protocols & Networking):** ความเข้าใจและประสบการณ์ด้าน TCP/IP Sockets, OPC (OPC UA / OPC DA), Modbus, Serial RS-232/485 และ RESTful API
* 💡 **ระบบสมองกลฝังตัวและฮาร์ดแวร์ (Embedded Systems & Hardware):** การเขียนโปรแกรมควบคุมไมโครคอนโทรลเลอร์ (ESP32, STM32, Arduino), การออกแบบวงจร และการแก้ปัญหาหน้างาน
* 🗄️ **ฐานข้อมูลและระบบสารสนเทศ (Databases & DevOps):** Microsoft SQL Server, MySQL, การเขียนคำสั่ง SQL ขั้นสูง, Git Version Control, Docker, WSL2 และ Linux Environment

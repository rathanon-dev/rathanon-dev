## **สรุปประวัติส่วนตัว**
สวัสดีครับ,**รฐนนท์ แสงรุ่งสว่าง** วิศวกรคอมพิวเตอร์ที่มีความสนใจในนวัตกรรมทางเทคโนโลยี การพัฒนาซอฟต์แวร์ และการควบคุมอัตโนมัติ เป้าหมายอาชีพของดิฉันคือการบูรณาการระบบ ERP และ PLC การปรับแต่งระบบ และการพัฒนาทั้งซอฟต์แวร์และฮาร์ดแวร์ ความเชี่ยวชาญของดิฉันรวมถึงการเขียนโปรแกรม การบูรณาการระบบ และการแก้ไขปัญหาที่ซับซ้อน ซึ่งช่วยให้ดิฉันมีความชำนาญทางเทคนิคที่จำเป็นในการทำงานที่เน้นการใช้งาน ERP และการดำเนินการระบบ PLC การควบคุมอัตโนมัติ และการเพิ่มประสิทธิภาพ

## **ความเชี่ยวชาญหลัก**
🔧 **การบูรณาการระบบ**: ประสบการณ์ในการบูรณาการและปรับแต่งระบบ ERP และ PLC  
🛠️ **เครื่องมือและเฟรมเวิร์ก**: เชี่ยวชาญในการใช้ Python, JavaScript, Node.js, Next.js, MySQL  
💡 **อิเล็กทรอนิกส์และการควบคุมอัตโนมัติ**: ความเข้าใจในการเขียนโปรแกรม PLC การออกแบบวงจร และการทำงานกับ ESP32, STM32  
🌐 **เครือข่ายและโปรโตคอล**: ความรู้เกี่ยวกับโปรโตคอลการสื่อสารทางเครือข่ายและการแก้ไขปัญหาระบบ  
🚀 **การเรียนรู้อย่างต่อเนื่อง**: มีความกระตือรือร้นในการสำรวจเทคโนโลยีใหม่ๆ และพัฒนาทักษะในการแก้ปัญหา

## **ทักษะทางเทคนิค**
- **ภาษาโปรแกรม**: Python, JavaScript, C#, C/C++, SQL  
- **การพัฒนาเว็บ**: Node.js, Next.js, React.js, Express.js  
- **ฐานข้อมูล**: MySQL  
- **การบูรณาการระบบ**: การปรับแต่งระบบ ERP, การเขียนสคริปต์สำหรับการทำงานอัตโนมัติ, การพัฒนา API  
- **PLC และระบบฝังตัว**: ความรู้พื้นฐานเกี่ยวกับ PLC, การออกแบบวงจร, การทำงานกับ ESP32, STM32  
- **เครือข่ายและโปรโตคอลการสื่อสาร**: ความเข้าใจใน TCP/IP, Modbus, MQTT และการแก้ไขปัญหาระบบ  
- **โครงสร้างพื้นฐาน IT**: Linux, Docker, Virtual Machines (VM), การบำรุงรักษาเซิร์ฟเวอร์

## **การศึกษา**
- ปริญญาตรีสาขาวิศวกรรมคอมพิวเตอร์ – สถาบันเทคโนโลยีพระจอมเกล้าลาดกระบัง  
- ปริญญาโทสาขาคอมพิวเตอร์เทคโนโลยี – วิทยาลัยเทคนิคลพบุรี  
- ประกาศนียบัตรวิชาชีพชั้นสูงสาขาอิเล็กทรอนิกส์ – วิทยาลัยเทคนิคลพบุรี

## **ประสบการณ์ทางวิชาชีพ**

  - ช่วยในการเขียนโปรแกรมและการทดสอบซอฟต์แวร์  
  - ทำงานในการแก้ไขปัญหาระบบและการดีบัก  
  - ได้รับประสบการณ์ในการพัฒนาซอฟต์แวร์และการควบคุมอัตโนมัติ  

- **ABU Robocon 2020 - ทีม LB.TECH ROBOT**  
  - เขียนโปรแกรมสำหรับหุ่นยนต์ในการควบคุมอัตโนมัติ  
  - พัฒนาการบูรณาการระบบระหว่างฮาร์ดแวร์และซอฟต์แวร์  
  - ทำงานกับไมโครคอนโทรลเลอร์และโปรโตคอลการสื่อสารแบบเรียลไทม์

## **โครงการและการวิจัย**
- **การปรับแต่งและบูรณาการระบบ ERP**  
  - พัฒนาสคริปต์และกระบวนการอัตโนมัติสำหรับการบูรณาการระบบ ERP  
  - ทำงานกับ API เพื่อเชื่อมต่อระบบ ERP และ PLC  
  - ปรับแต่งการทำงานของ ERP และอินเตอร์เฟซผู้ใช้เพื่อเพิ่มประสิทธิภาพการดำเนินงาน

- **ระบบทดสอบออนไลน์ใช้ Google Form API**  
  - พัฒนาระบบทดสอบออนไลน์โดยใช้ Next.js และ Express.js  
  - รวมกับ Google Forms API สำหรับการประมวลผลการทดสอบอัตโนมัติ  
  - เก็บผลการทดสอบในฐานข้อมูล MySQL สำหรับการวิเคราะห์และรายงานข้อมูล

- **โครงการอิเล็กทรอนิกส์และการควบคุมอัตโนมัติ**  
  - ออกแบบและพัฒนาระบบฝังตัวโดยใช้ ESP32 และ STM32  
  - ดำเนินการเขียนโปรแกรม PLC พื้นฐานสำหรับงานควบคุมอัตโนมัติ  
  - พัฒนาโซลูชัน IoT สำหรับการเก็บข้อมูลและการตรวจสอบแบบเรียลไทม์

- **โครงสร้างพื้นฐาน IT และการบริหารระบบ**  
  - เชี่ยวชาญใน Linux, Docker, และ Virtual Machines (VM)  
  - มีทักษะในการแก้ไขปัญหาการบำรุงรักษาเซิร์ฟเวอร์  
  - ความเข้าใจในด้านความปลอดภัยเครือข่าย การเพิ่มประสิทธิภาพระบบ และการจัดการโครงสร้างพื้นฐาน

- มีความรับผิดชอบ กระตือรือร้น และสามารถปรับตัวได้กับความก้าวหน้าทางเทคโนโลยี  
- มีทักษะการวิเคราะห์และการแก้ปัญหาที่ดี  
- มีความหลงใหลในการบูรณาการระบบ การควบคุมอัตโนมัติ และการพัฒนาเทคโนโลยี  
- กระตือรือร้นที่จะนำความเชี่ยวชาญของฉันในการบูรณาการ ERP และ PLC การเขียนสคริปต์ และการแก้ไขปัญหามาใช้ในการพัฒนาและการพัฒนาเทคโนโลยีใหม่ ๆ

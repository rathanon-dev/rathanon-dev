# รฐนนท์ แสงรุ่งสว่าง (Rathanon Sangrungsawang) 👋

[![en](https://img.shields.io/badge/lang-en-red.svg)](https://github.com/rathanon-dev/rathanon-dev/edit/main/README.md)
[![TH](https://img.shields.io/badge/lang-th-green.svg)](https://github.com/rathanon-dev/rathanon-dev/edit/main/README.th.md)

สวัสดีครับ! ผมชื่อ **รฐนนท์ แสงรุ่งสว่าง** เป็น **วิศวกรคอมพิวเตอร์** ที่มีความสนใจในด้าน **เทคโนโลยี**, **การเขียนโปรแกรม**, และ **อิเล็กทรอนิกส์** ตอนนี้กำลังมองหางานในด้าน **วิศวกรรมซอฟต์แวร์**, **วิศวกรรมฮาร์ดแวร์**, หรือ **งานบำรุงรักษาและการพัฒนา Production** โดยผมมีทักษะในการใช้ภาษาโปรแกรมต่างๆ เช่น C#, C/C++, Python และ JavaScript รวมทั้งมีประสบการณ์ในการพัฒนาแอปพลิเคชันเว็บ การออกแบบวงจรไฟฟ้า และอื่นๆ

## ข้อมูลเกี่ยวกับผม
- 🔧 **วิศวกรรมซอฟต์แวร์**: มีประสบการณ์ในการพัฒนาเว็บแอปพลิเคชันและบริการด้าน Backend
- 🛠️ **เครื่องมือและเฟรมเวิร์ก**: คุ้นเคยกับ Node.js, Next.js, MySQL
- 💡 **อิเล็กทรอนิกส์**: การออกแบบวงจรไฟฟ้าและการทำงานกับโมดูล เช่น ESP32 และ STM32
- 🚀 **การเรียนรู้**: สนุกกับการเรียนรู้เทคโนโลยีใหม่ๆ และพัฒนาทักษะการเขียนโปรแกรมและการแก้ปัญหา

## ทักษะ
- **ภาษาโปรแกรม**: C#, C/C++, Python, JavaScript, SQL
- **การพัฒนาเว็บ**: Node.js, Next.js, React.js
- **ฐานข้อมูล**: MySQL
- **อิเล็กทรอนิกส์**: การออกแบบวงจรไฟฟ้า, การทำงานกับโมดูล ESP32, STM32 ฯลฯ
- **ทักษะอื่นๆ**: การขับขี่จักรยานยนต์, Linux เบื้องต้น, Docker, VM (Cloud VPS)

## การศึกษา
- ปริญญาตรี **วิศวกรรมศาสตร์** สาขาวิศวกรรมคอมพิวเตอร์, สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง
- ปวส. **เทคโนโลยีคอมพิวเตอร์**, วิทยาลัยเทคนิคลพบุรี
- ปวช. **อิเล็กทรอนิกส์**, วิทยาลัยเทคนิคลพบุรี

## ประสบการณ์การทำงาน
- **ฝึกงานที่บริษัท ไพรมัส จำกัด (เมษายน 2562 - กันยายน 2562)**  
  พัฒนาและดูแลซอฟต์แวร์ต่างๆ ที่ได้รับมอบหมาย พร้อมได้รับประสบการณ์ในการเขียนโปรแกรมและการแก้ปัญหาในสภาพแวดล้อมจริง
- **การแข่งขัน ABU Robocon 2020 - ทีม LB.TECH ROBOT**  
  แข่งขันในรายการ ABU Robocon 2020 โดยมีหน้าที่ในการเขียนโปรแกรมสำหรับหุ่นยนต์และเว็บแอปพลิเคชัน
- **ระบบการทดสอบออนไลน์โดย Google Form API**  
  พัฒนาระบบการทดสอบออนไลน์โดยใช้ Google Form API เว็บแอปพลิเคชันนี้ใช้ Next.js สำหรับส่วน Frontend และ Express.js สำหรับการเชื่อมต่อ API กับฐานข้อมูล ระบบนี้ช่วยให้ผู้ใช้สามารถทำการทดสอบออนไลน์ได้ โดยผลลัพธ์จะถูกส่งผ่าน Google Form และข้อมูลจะถูกเก็บใน Backend เพื่อการวิเคราะห์เพิ่มเติม

## โครงการ
- **การพัฒนาเว็บแอปพลิเคชัน**: สร้างและปรับใช้แอปพลิเคชันเว็บโดยใช้ Next.js และ Express.js
- **โครงการอิเล็กทรอนิกส์**: ออกแบบวงจรและทำงานกับโมดูลต่างๆ เช่น ESP32, STM32

## ผลงานทางวิชาการ/บทความ/รางวัลเกียรติยศ/ผลงานวิจัย
- **ผลงานการแข่งขันหุ่นยนต์ ABU Robocon 2020**:  
  เข้าร่วมการแข่งขันหุ่นยนต์ระดับประเทศในฐานะสมาชิกทีม LB.TECH ROBOT  
  รับผิดชอบงานด้านการเขียนโปรแกรมหุ่นยนต์เพื่อให้ทำงานตามโจทย์การแข่งขัน
- **โครงการพัฒนาแอปพลิเคชันเว็บระบบการทดสอบออนไลน์โดย Google Form API**:  
พัฒนาระบบการทดสอบออนไลน์โดยใช้ Google Form API ที่ช่วยให้ผู้ใช้สามารถทำการทดสอบออนไลน์ได้ โดยผลลัพธ์จะถูกส่งผ่าน Google Form และข้อมูลจะถูกเก็บใน Backend เพื่อการวิเคราะห์เพิ่มเติม ระบบนี้ถูกใช้เป็นส่วนหนึ่งของการศึกษาในระดับปริญญาตรีและมีการนำเสนอต่อคณะกรรมการในโครงการวิจัยทางเทคโนโลยี
- **ผลงานวิจัยขนาดเล็กด้านระบบฝังตัว (Embedded Systems)**:  
  ออกแบบและพัฒนาระบบฝังตัวโดยใช้ไมโครคอนโทรลเลอร์ เช่น ESP32 และ STM32
- **รางวัลและเกียรติบัตร**:  
  เกียรติบัตรจากการแข่งขันและกิจกรรมที่เกี่ยวข้องกับงานด้านวิศวกรรมและไอที เช่น ABU Robocon 2020

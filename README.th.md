## 📌 สรุปข้อมูลความเชี่ยวชาญ (About Me)
- 🔧 **วิศวกรรมระบบและระบบควบคุม:** พัฒนาแอปพลิเคชันเชื่อมต่อเครื่องจักร (Automation Host), สื่อสารกับ PLC ผ่าน TCP/IP และ OPC
- 💻 **การพัฒนาซอฟต์แวร์:** เชี่ยวชาญภาษา C#, .NET, Python, C/C++, TypeScript, Node.js, Next.js และฐานข้อมูล SQL
- 💡 **ระบบสมองกลฝังตัวและฮาร์ดแวร์:** ประสบการณ์ระบบควบคุมมอเตอร์หุ่นยนต์ (ABU Robocon 2020), ไมโครคอนโทรลเลอร์ ESP32, STM32 และการสื่อสารเครือข่าย NB-IoT
- 🚀 **การเรียนรู้เชิงลึก:** มีความสามารถในการวิเคราะห์สถาปัตยกรรมระบบ การทำ Reverse Engineering และการแก้ไขปัญหาทางวิศวกรรมที่ซับซ้อน

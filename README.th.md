
# สวัสดีครับ ผมชื่อ รฐนนท์ แสงรุ่งสว่าง 👋
[![en](https://img.shields.io/badge/lang-en-red.svg)](https://github.com/rathanon-dev/rathanon-dev/edit/main/README.md)
[![TH](https://img.shields.io/badge/lang-th-green.svg)](https://github.com/rathanon-dev/rathanon-dev/edit/main/README.th.md)

ผมเป็น **วิศวกรคอมพิวเตอร์** ที่มีความสนใจในด้านเทคโนโลยี การเขียนโปรแกรม และอิเล็กทรอนิกส์ ตอนนี้กำลังมองหางานในด้าน **วิศวกรรมซอฟต์แวร์** **วิศวกรรมฮาร์ดแวร์** หรือ **งานบำรุงรักษาและการพัฒนา Production** ซึ่งผมมีทักษะในการใช้ภาษาโปรแกรม เช่น C#, C/C++, Python และ JavaScript รวมทั้งประสบการณ์ในด้านการพัฒนาแอปพลิเคชันเว็บ การออกแบบวงจรไฟฟ้า และอื่นๆ

## ข้อมูลเกี่ยวกับผม

- 🔧 มีประสบการณ์ใน **วิศวกรรมซอฟต์แวร์** รวมถึงการพัฒนาเว็บแอปพลิเคชันและบริการด้าน Backend
- 🛠️ฉันมีทักษะในการใช้งาน **เครื่องมือและเฟรมเวิร์ก** เช่น **Node.js**, **Next.js** และ **MySQL**
- 💡 คุ้นเคยกับ **วงจรอิเล็กทรอนิกส์** และโมดูลต่างๆ เช่น **ESP32** และ **STM32**
- 🚀 สนุกกับการเรียนรู้เทคโนโลยีใหม่ๆ และพัฒนาทักษะการเขียนโปรแกรมและการแก้ปัญหา

## ทักษะ

- **ภาษาโปรแกรม**: C#, C/C++, Python, JavaScript, SQL
- **การพัฒนาเว็บ**: Node.js, Next.js, React.js
- **ฐานข้อมูล**: MySQL
- **อิเล็กทรอนิกส์**: การออกแบบวงจรไฟฟ้า, การทำงานกับโมดูล ESP32, STM32 ฯลฯ
- **ทักษะอื่นๆ**: การขับขี่จักรยานยนต์, Linux เบื้องต้น, Docker, VM (Cloud VPS)

## การศึกษา

- **ปริญญาตรี วิศวกรรมศาสตร์ สาขาวิศวกรรมคอมพิวเตอร์** , สถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง
- **ปวส. สาขาเทคโนโลยีคอมพิวเตอร์**, วิทยาลัยเทคนิคลพบุรี
- **ปวช. สาขาอิเล็กทรอนิกส์**, วิทยาลัยเทคนิคลพบุรี

## ประสบการณ์การทำงาน

### ฝึกงานที่บริษัท ไพรมัส จำกัด (เมษายน 2562 - กันยายน 2562)
- พัฒนาและดูแลซอฟต์แวร์ต่างๆ ที่ได้รับมอบหมาย
- ได้รับประสบการณ์ในการเขียนโปรแกรมและการแก้ปัญหาในสภาพแวดล้อมจริง

### การแข่งขัน ABU Robocon 2020 - ทีม LB.TECH ROBOT
- แข่งขันในรายการ ABU Robocon 2020 โดยมีหน้าที่ในการเขียนโปรแกรมสำหรับหุ่นยนต์และเว็บแอปพลิเคชัน ใช้ **Next.js** สำหรับส่วน frontend และ **Express.js** สำหรับการเชื่อมต่อ API กับฐานข้อมูล

## โครงการ

- **การพัฒนาเว็บแอปพลิเคชัน**: สร้างและปรับใช้แอปพลิเคชันเว็บโดยใช้ Next.js และ Express.js
- **โครงการอิเล็กทรอนิกส์**: ออกแบบวงจรและทำงานกับโมดูลต่างๆ เช่น ESP32, STM32
